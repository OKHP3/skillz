In an earlier post, I wrote about designing a reusable workflow. That design now has a concrete form: a reusable template committed to the repository.

A design can describe how a workflow should go. A template asks a more practical question: what can stay the same each time, and what does someone need to decide for the case in front of them?

That’s the distinction I’d use to review any reusable workflow. Which decisions should the template carry forward, and which should it leave open?
