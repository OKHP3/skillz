### Public draft

When I’m testing a change to an agent workflow, the first question I want to answer is what the agent can already do without the change.

That’s where a baseline earns its keep. Give both versions the same task and use the same criteria to judge their answers. Before running either one, decide what would make the change worth keeping. Is it fewer corrections? Better handling of an ambiguous request? Less time spent reviewing the output?

I’d start with a task where that difference would matter in practice. What would you want to see before adding a step to an agent workflow?
