# Series record template

Store a populated record only in the owner's authorized workspace. This is a
template, not a registry or permission to publish.

| Field | Record |
|---|---|
| Intended audience and purpose | Runtime-supplied context |
| Prior item and source | Neutral identifier and evidence location |
| Item state | draft / scheduled / published / unknown |
| Observation | Time, timezone, source, and visibility limits |
| Prior insight | Supported summary, or unknown if inaccessible |
| New insight | Proposed continuation and overlap assessment |
| Claim ledger | Claim, source, contribution, completion, confidence and limits |
| Disclosure | Public / private / needs owner review, with private sources kept private |
| Voice basis | Owner-authored sample / owner direction / assistant draft / unavailable |
| CTA and links | One primary destination or action; role of each supplied link |
| Handoff | Draft location, evidence location and owner-review state |

Mark scheduled items separately from a publication receipt. Never mark a
synthetic example as a real career achievement, or a baseline tie as uplift.
