# Manual Send Checklist

For the sender to use by hand, one invitation at a time, in their own session.
The assistant does not click, type, or submit for the sender.

1. Open the recipient's profile from the wave list.
2. If the profile already shows Pending or Connected, skip it and mark it.
3. Find Connect. It can sit in the profile's "More" actions menu.
4. If Connect is missing, or the dialog asks for the recipient's email, skip
   the profile and mark the reason. Do not guess an email.
5. Choose the option to add a note, paste the approved text, and check that it
   fits the limit shown in the dialog.
6. Send. Confirm the Pending state on the profile.
7. Mark the row sent with the date. Move to the next profile at a natural
   pace, not in a rapid burst.
8. After the wave, compare the sent-invitations count with the expected total
   and note any gap.

Stop and wait if LinkedIn shows a limit or a warning notice. Withdrawing
invitations does not lift a limit restriction.
