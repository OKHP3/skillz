# LinkedIn message surfaces and limits

Treat every number here as a planning default, not a guarantee. LinkedIn
changes these limits by account type and over time, and public sources
disagree. Confirm the live character counter before treating a draft as
ready.

| Surface | Planning default | Notes |
|---|---|---|
| Existing conversation (first-degree connection) | No practical short limit; keep it readable on a phone | Attachments are usually available in the composer; confirm in the host |
| Connection-request note, basic account | Write to 200 characters | Secondary sources report a monthly cap on personalized notes for basic accounts |
| Connection-request note, premium account | Up to 300 characters on some surfaces | Still confirm the counter |
| InMail | Subject up to 200 characters; keep the body under 1,900 characters | Some sources report 2,000 for the body; 1,900 is the safe default |

## Source status

Retrieved 2026-11-09. The LinkedIn Help pages that state these limits could
not be fetched by the authoring agent, so the defaults above rest on
secondary sources that cite LinkedIn Help and conflict with each other:

- [Hublead: LinkedIn character limits](https://www.hublead.io/linkedin-character-limit) reports 200 characters for an invitation note, citing a LinkedIn Help page checked in 2026, and notes that many articles still state the older 300-character limit.
- [Phantombuster: new LinkedIn limits](https://phantombuster.com/blog/?p=4371) reports 200 characters for free accounts and 300 for premium accounts.

When the live counter disagrees with this table, the counter wins. Record the
observed limit in the gate report.
