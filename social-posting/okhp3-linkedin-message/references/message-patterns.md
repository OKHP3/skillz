# LinkedIn message patterns

Observed behavior, last checked 2026-11. Verify limits on screen before relying
on any number here.

## Surfaces and limits

| Surface | Typical length | Limit note |
|---|---|---|
| Connection-request note | 1 to 3 sentences | Ceiling varies by account and plan. One account showed a 200-character counter; older documentation cites 300. Trust the live counter. |
| First-degree DM | 60 to 200 words | No practical limit; length should match the other person's message. |
| InMail (to a non-connection) | 80 to 200 words | Uses a paid credit on some plans. A reply to an incoming recruiter InMail is usually free. Confirm before spending a credit. |
| Reply in an existing thread | Mirror the inbound length | Quote or restate the question being answered. |

Some profiles present Follow as the primary action. The Connect command is then
under the profile More menu.

## Thank-you for connecting

Three parts, in order: thanks for connecting, one specific thing taken from the
connection's own reply or post (proof it was read), and at most one low-cost
offer. No ask. Example shape with placeholders:

> <FIRST_NAME>, thanks for connecting and for the thoughtful reply on <POST_TOPIC>.
>
> Your point that <THEIR_SPECIFIC_POINT> is the piece I was missing, because <WHY_IT_MATTERS>. If it would help your follow-up, I'm happy to share <OFFER>.

## Changed-terms reply

Use when a recruiter or contact revises rate, location, schedule, or scope after
interest was expressed.

1. Acknowledge the change without agreeing to it.
2. Restate the original terms neutrally so the change is on the record.
3. Ask whether the new figure or requirement is fixed or flexible, and what the
   flexibility depends on.
4. Offer availability for a call and state what would be decided on it.
5. Keep numbers out of writing unless the user says to include them.

## Verify-before-sharing reply

When an unsolicited recruiter asks for a résumé or personal data, ask for the
requisition number or posting link, the engagement type with the client, and the
hiring manager's team. Say a résumé follows once the role is verified. Pair with
`okhp3-recruiter-legitimacy-check`.

## Attachment handoff

Write the message so it reads correctly with the attachment, then tell the user:
file name, where it is stored, and that it must be attached in the composer
before sending. Do not write "attached" if the user has not confirmed that step.
