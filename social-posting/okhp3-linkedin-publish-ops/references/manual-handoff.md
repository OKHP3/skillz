# Manual handoff checklist (default mode)

Fill the placeholders from the publish bundle and give the user the matching
section. Labels are from the English (US) web interface as observed on
2026-11-09; they may differ by locale or after an interface change.

## Public artifact boundary

Identity-agnostic. Placeholders only.

## Schedule a new post

1. Open the feed and select **Start a post**.
2. Paste or type `<POST_TEXT>`. Check that paragraph breaks survived; pasting
   can drop them.
3. If there is a document: select **+** (more), then the document option,
   choose `<DOCUMENT_PATH>`, type the title `<DOCUMENT_TITLE>`, and select
   **Done**. Check the page count shows `<PAGE_COUNT>`.
4. Check there is no link-preview card. If one appeared, remove it before
   going on.
5. Select the clock icon. Set the date to `<DATE>` and the time to `<TIME>`.
6. Read the "posting at" line and confirm it says `<DATE> <TIME>` in
   `<TIME_ZONE>`. Select **Next** or **Confirm**, then **Schedule**.
7. Reopen the scheduled list (composer, clock icon, **Scheduled**) and confirm
   the entry is there once.

## Change a scheduled post

- **Move it:** scheduled list, the post's **...** menu, **Modify schedule**.
- **Edit text:** **...**, **Edit post**. Text edits save; a document cannot be
  added here.
- **Add a document:** create a new post with the text and the document,
  schedule it for the same time, confirm it is in the list, then delete the old
  copy with **...**, **Delete post**.
- **Swap two posts:** modify each schedule in turn, then confirm both entries
  in the list.

## Post the first comment at go-live

1. Open the live post and select **Comment**.
2. Paste `<FIRST_COMMENT>`. In a comment box, Enter submits; use Shift+Enter
   for a line break.
3. Select the comment's **Comment** button once. Expand **more** on the
   rendered comment and check the full text, including `<HASHTAGS>`.

## Tell the agent

Reply with "done" plus anything that looked different. If the agent can read
the page, it verifies the result and logs it.
