# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for **Skillz
Forge** (`forge/`), the React+Vite catalog app in this repository.

## Index

| ADR | Title | Status | Date |
| --- | --- | --- | --- |
| [0001](0001-family-requires-family-md.md) | A top-level directory is only a catalog "family" if it contains FAMILY.md | Accepted | 2026-08-03 |

## Creating a New ADR

1. Copy the shape of `0001-family-requires-family-md.md` to `NNNN-title-with-dashes.md`.
2. Fill in Context / Decision Drivers / Considered Options / Decision / Consequences.
3. Update this index.

## ADR Status

- **Proposed**: Under discussion
- **Accepted**: Decision made, implemented
- **Deprecated**: No longer relevant
- **Superseded**: Replaced by another ADR
- **Rejected**: Considered but not adopted
