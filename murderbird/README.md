# MurderBird

**Status: early specific tooling.** Editorial red-team and thesis-building
skills for the MurderBird agent persona.

MurderBird finds what doesn't hold. These packages give any compatible agent
that job as a method: audit an argument before it ships, or forge a thesis
that can survive contact.

## Current packages

- `okhp3-murderbird-argument-audit/` stress-tests a draft and returns a
  verdict, load-bearing claims table, weakest point, and salvage list.
- `okhp3-murderbird-thesis-forge/` turns a research packet or rough idea into
  a one-sentence thesis, structure, hooks, and a hard ending.
- `okhp3-murderbird-hook-and-close/` forges and scores the opening and closing
  lines of short posts so the hook earns attention honestly and the close lands.

## Not this family

Security and agentic-threat red teaming lives in `red-teaming/`. Final voice
lives in `okhp3-linkedin-voice`. See `FAMILY.md` for the full boundary.
