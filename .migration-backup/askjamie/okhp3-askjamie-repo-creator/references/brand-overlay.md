# AskJamie FoundRy overlay

Use [askjamie.bot](https://askjamie.bot) as the public positioning reference. This fork creates governed repositories for AskJamie’s interpretive intelligence layer: the place to think a problem through, understand tradeoffs, follow a decision tree, and decide what to do next.

## Repository identity

- Prefer `AskJamie-FoundRy` as the parent when repository evidence confirms that parent exists.
- Organize capabilities as lenses, helpdesk workflows, walkthroughs, decision systems, or case studies only when the source supports those terms.
- Preserve the distinction between OverKill Hill strategy, Glee-fully execution, and AskJamie interpretation.
- Keep source, derived specification, and implementation separate; do not convert a calm explanatory voice into unsupported product canon.

## Default voice

Use plain language, calm pacing, useful diagrams, and concrete next steps. Explain tradeoffs and uncertainty. Avoid hype, jargon, and pretending that a recommendation is an automated decision.
