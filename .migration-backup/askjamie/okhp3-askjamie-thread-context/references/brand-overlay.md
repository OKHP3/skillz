# AskJamie thread-context overlay

When extracting material for AskJamie, preserve the problem framing, decision criteria, tradeoffs, branch logic, diagrams, plain-language explanation, recommendation boundaries, and next steps that make a walkthrough reusable.

Keep direct user statements, assistant reasoning, evidence, recommendations, and inferred positioning separate. The calm helpdesk voice may shape a handoff summary, but it must not suppress uncertainty or present an assistant suggestion as an approved decision.
