# AskJamie ChatGPT migration overlay

Route reviewed, public-safe ChatGPT project material into AskJamie’s interpretive layer. Preserve the original project identity and provenance before translating it into lens, helpdesk, walkthrough, or decision-support records.

## Required interpretation

- Treat AskJamie positioning as evidence of purpose and tone, not proof that every conversation is product canon.
- Preserve questions, options, tradeoffs, reasoning, branch logic, diagrams, decisions, and next actions as labeled fields when present.
- Keep strategy source, execution instructions, recommendations, private context, and uncertain assistant claims distinct.
- Use `askjamie` routing only when the project evidence supports it; otherwise retain a neutral migration record.
- A migrated record must explain what was preserved, transformed, omitted, and still needs owner review.
