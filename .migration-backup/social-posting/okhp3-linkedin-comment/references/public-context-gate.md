# LinkedIn Comment Public-Context Gate

Run this gate after the voice pass and before returning a comment draft.

- Confirm the target post, parent comment when relevant, acting account, and
  public destination. A headline or screenshot fragment is not enough.
- Tie consequential claims to supplied public evidence. For repository activity,
  record the public ref, bounded observation window, timezone, retrieval time,
  and source location. Do not present a plan, unrun test, or pending result as
  completed.
- Keep contest, award, application, and voting outcomes conditional until an
  authoritative result confirms them. Humor may acknowledge the uncertainty;
  it must not disguise a claim of victory.
- Remove employer, client, household, customer, private, and identifying detail
  that is not approved public context. Generalize the underlying insight when it
  survives without the detail.
- Keep one primary link. Preserve user-supplied secondary links only when each
  has a distinct role and remains relevant to the parent conversation.
- Preserve an explicitly requested hashtag count. Do not add campaign tags by
  habit or invent account mentions.
- Return the draft and gate report only. Explicit user approval for publication
  does not authorize this skill to send the comment; a host publisher must own
  that action and verify the rendered result separately.
