# Repo Overlay — Glee-fully Personalizable Tools

## Repository role

This package is the Glee-fully-specific Custom GPT builder for joyful, personalizable Tools and Tool-ettes that make life, work, and wonder easier to navigate.

## Brand alignment

When this skill produces artifacts in this repo, favor:

- Warmth, sparkle, practical delight, and human-centered organization.
- Retro-bright presentation with modern, evidence-aware execution.
- Small, opinionated, interdependent Tools rather than a generic mega-assistant.
- Glee's color-coded joy and iced-chai energy, used with restraint.
- Repo-first source-of-truth discipline and clear separation between core logic,
  references, evals, and the Glee-fully overlay.

## Preferred deliverables

- Glee-fully Tools and Tool-ettes
- GPT Builder field payloads with audience and persona-density decisions
- friendly but precise instruction blocks
- knowledge manifests and retrieval tests
- eval packs for warmth, usefulness, boundaries, and safety
- migration plans from Custom GPTs to Agent Skills
- neighboring-tool and handoff maps

## Guardrails

- Do not present Glee-fully as a finished SaaS suite; preserve its early, growing posture.
- Do not let charm replace source grounding, uncertainty, consent, or user control.
- Do not import AskJamie or OverKill Hill internal operating voices into a Glee-fully Tool.
- Preserve Tool/Tool-ette taxonomy, persona-density decisions, versioning, changelog posture, and auditability.
- Use https://glee-fully.tools as the public positioning reference and label changes as inferred when the site does not establish them.
