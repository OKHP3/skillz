# Ledger fields, statuses, and templates

## Fields (one row per person)

| Field | Notes |
|---|---|
| Name and profile link | |
| Relationship tier | Inner circle, leader, peer, outsider |
| Contact rules | Any restriction the user supplied for this person |
| Offer type | Reference, referral, introduction, recommendation, comment, call |
| Offer quote | Their exact words, short |
| Date offered | |
| Specific ask made | Company, role, one-line fit, exact request |
| Ask date | |
| Status | offered, asked, delivered, thanked, stale |
| Next follow-up date | Offer date plus 7 days if no ask yet; ask date plus 7 days if no delivery |
| Channel | Message, text, email, phone |

## Ask template

> <FIRST_NAME>, you mentioned you would be glad to help. I'm applying for
> <ROLE> at <COMPANY> because <ONE_LINE_FIT>. Would you be willing to
> <EXACT_REQUEST>? If it helps, I can send a short note you can forward.

## Recommendation request

Provide two or three suggested points drawn from work the person actually saw,
and make declining easy.

## Thank-you template

> <FIRST_NAME>, thank you for <WHAT_THEY_DID>. <ONE_LINE_RESULT_OR_NEXT_STEP>.
> I'll keep you posted.
