# Frozen matched trial for Project Compass 1.3.0

## Design

One fresh ephemeral Codex CLI execution per case per condition. The five existing cases keep their exact prompts, fixtures as specified, and 20 expectation texts in the parent evals.json. The fixture generator instantiates missing evidence synthetically. A sixth case comes from a separate fresh fixture author with a broad task description, no file tools, no package, and no access to either the existing cases or executor outputs. Its four checks are frozen before baseline execution. This is an independent synthetic transfer observation. The external protected holdout has a separate disposition.

The control receives the owner prompt, fixture metadata and fixture interface. The treatment receives the same plus the pinned candidate SKILL.md and on-demand read access to its bundled references, assets and helpers. No eval, historical learning record, or original grading text is available to executors. Selecting the skill is deliberate. Automatic activation is outside this trial. Each fixture is reset between runs. One replication per arm per case, up to six concurrent, with a 360-second wall budget for each executor. Provider transport failures or missing fixture transport may be retried once with the same inputs; incomplete substantive outputs and ordinary helper failures cannot be rerolled. A time limit with substantive tool work is retained and scored from captured artifacts. Missing infrastructure evidence is recorded as unavailable. All substantive runs and retries must be accounted for. Use medium reasoning effort and the same requested model for both arms.

Codex starts outside any project in an empty neutral directory with user configuration ignored, ephemeral sessions, host skill discovery skipped, shell, browser, plugins, apps, memory and multi-agent disabled. Scored activity must come through the fixture tool. No live GitHub writes, scheduler installations, commits, or publication. Record any requested simulated external action. Synthetic Git origins are local metadata with no commit history. The forge snapshot and offline helper inputs use the same observations. Normalizing an ephemeral directory to a relative locator is permitted in public outputs. The independent case has its own narrative dates. Other case file ages are measured at 2026-11-24, and host wall time remains observable to helpers.

## Scoring

Give a fresh grader one submission at a time with an opaque ID, the fixture evidence, case expectations, answer, persisted edits and action evidence. Withhold arm labels, helper installation details, runner receipts, freeze maps and the opposing response. Normalize tool activity for grading to file changes, attempted external actions and attempted remote/approved-plan calls. Ordinary wording can reveal use of a skill, so label blinding does not guarantee concealment. Every conjunct of an expectation is required. Negative-action clauses rely on the captured trace. Missing evidence fails a substantive criterion. An absent trial is unavailable. Keep original first valid grades and supporting locators. Invalid grader JSON may receive one fresh same-packet retry.

Task quality is the mean of the 12 binary expectations in the three noncritical development cases. The frozen floor is at least 0.90. Matched uplift is candidate minus control in percentage-point units on the same 12 checks, floor +0.50. Also report the paired delta on all 20 published checks to expose the aggregation choice left unspecified in the original. Each critical case requires 4/4 for the candidate. Independent transfer is reported separately, with no invented acceptance floor. No compensatory averaging, pooling with holdout, tuning, or post-hoc expectation changes. An observed numerical pass is limited to these single draws. Missing external custody is an open release-evidence gap.

## Freeze and replay

freeze.json binds the original files, inputs, runner, grader instructions and this protocol before launching any scored run. candidate.json binds the later stable candidate runtime payload under SKILL.md, references, scripts and assets before treatment. Original eval files remain historical. Retain both manifests, exact prompts, fixture generator and inputs, answer texts, file differences, action transcripts, time/token receipts and binary grades. Use run.py and grade.py with Python 3 on macOS, the recorded Codex CLI/model, a logged-in CLI, a neutral empty /var/empty, and sandbox-exec. Replays are stochastic. See README.md for exact invocation and results.
