# Pre-treatment transport correction

The original transport allowed repository writes only in the fixture. macOS Git also opens the null device for reading and writing. The sandbox denied that open. On identical Git metadata, the unrestricted control identified the worktree and the sandboxed invocation exited 128. This would conflate a healthy Git binary with the separately requested Git-outage condition. The unsuccessful initial supplemental probe is retained as probe-development.json.

Before any treatment output, repeat the complete control arm and use the same corrected transport for all six treatment runs. The only adapter change grants writes to /dev/null, a data sink. Model, effort, prompts, fixture bytes, case allocation, fresh contexts, time limit, grader, rubric and thresholds remain as originally frozen. The original six baseline outputs and grades stay on record with baseline-key.json as a pilot; they cannot substitute for the corrected baseline. There is no performance-based selection between cohorts. transport-freeze.json records the change and its timestamp. Authentication, network and real remote writes remain unavailable through the fixture adapter.
