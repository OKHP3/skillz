# Exclusion screen

Check the draft against every row. Flag and soften; do not silently drop content
the user stated.

| Item | Rule |
|---|---|
| Compensation, rate, or target figures | Keep out of written addenda unless the user says to include them. |
| Other employment or restricted affiliations | Exclude when the user has said it must not appear. Do not hint at it. |
| Former-employer confidential detail | Use only public facts or what the user confirms is public. Ask when unsure. |
| Internal politics, named colleagues, tool-ownership disputes | Rewrite as neutral ownership and funding facts, or omit. |
| Disparagement | Rewrite or omit. |
| Private contact details | Include only the details the user authorizes for this recipient. |
| Unverified numbers, dates, titles | Mark for confirmation; do not write as fact. |
| Quoted or fictional material | Do not invent quotes or references. |
| Degrees or credentials the user excludes | Exclude exactly as instructed. |

## Register check

Reread as the recipient. If it reads like a requirements document, rebuild it as
paragraphs. If a paragraph carries two ideas, split it. If a sentence only
decorates, cut it.
