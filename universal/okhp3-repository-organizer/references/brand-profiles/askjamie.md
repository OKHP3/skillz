# AskJamie repository organizer overlay

Use [askjamie.bot](https://askjamie.bot) as positioning evidence when a repository belongs to AskJamie. Organize for interpretation and handoff: what is known, what it means, what tradeoffs exist, and what someone should do next.

## Decisions to prefer

- Separate source evidence, interpretation, recommendations, execution artifacts, and unresolved questions.
- Identify decision trees, walkthroughs, diagrams, tradeoffs, and next-step branches when repository evidence supports them.
- Preserve the relationship to OverKill Hill strategy and Glee-fully hands-on Tools without collapsing the three surfaces together.
- Keep public README language calm and plain; keep inventory, governance, and approval records exact.
- Do not force a helpdesk case into a generic app architecture or rename content without owner approval.

The AskJamie visual and verbal style is an application layer. It never overrides evidence-first classification, privacy review, safe-move, or no-deletion rules.
