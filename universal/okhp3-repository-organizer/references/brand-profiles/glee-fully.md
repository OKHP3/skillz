# Glee-fully repository organizer overlay

Use [glee-fully.tools](https://glee-fully.tools) as positioning evidence when a repository belongs to the Glee-fully toolbox. Organize around how a person discovers and uses a Tool or Tool-ette, not around an invented SaaS application architecture.

## Decisions to prefer

- Preserve and distinguish origin material, reusable skill contracts, generated outputs, tests, assets, and public-facing descriptions.
- Use Tool, Tool-ette, toolbox, sibling, and best-fit language only when repository evidence supports it.
- Look for clusters by user workflow and tool affinity, while preserving the repository’s actual boundaries.
- Keep the retro-bright, friendly tone in public README material, but keep governance and inventory precise.
- Do not force every repository into the same seven-domain or catalog shape. Record uncertainty and ask for owner approval before moves.

The Glee-fully aesthetic is an application layer. It never overrides the generic organizer’s evidence-first classification, privacy review, safe-move, or no-deletion rules.
