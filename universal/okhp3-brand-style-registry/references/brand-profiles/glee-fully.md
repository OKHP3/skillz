# Glee-fully brand overlay

Use [glee-fully.tools](https://glee-fully.tools) as the primary public reference for this fork. Glee-fully presents a retro-bright toolbox of personalizable Custom GPTs for life, work, and wonder. Its design direction is warm friendship rather than friction: color-coded joy, playful organization, iced-chai energy, humor, and a retro design language paired with modern brains.

## Capture and application rules

- Record observed site evidence separately from inferred design interpretation and owner-declared rules.
- Prefer a bright, friendly, personalizable profile with clear hierarchy, approachable controls, and playful but usable accents.
- Apply one primary Glee-fully profile. Supporting profiles require an explicit role and must not flatten Glee-fully into a generic “fun” palette.
- Use the profile for Glee-fully surfaces, Tools, and Tool-ettes. Do not copy logos, proprietary artwork, or third-party marks.
- Preserve accessibility, contrast, responsive behavior, and user approval over decorative fidelity.

## Naming and handoff

Use `glee-fully` as the stable profile identifier unless the target repository has a stronger local convention. Describe the result as Glee-fully-aligned, not as official brand authority, unless the source explicitly establishes that authority.
