# Software Reclamation promotion handoff

This directory records a local promotion handoff for the Software Reclamation family. It is not publication authorization, a commit, a push, a pull request, or evidence that the skills have been run against a live application.

The family contains 15 OKHP3-authored remastered editions. They retain source lineage for provenance, but they are not renamed clones or verbatim copies of the community material. The packages add explicit scope, authorization, evidence tiers, uncertainty handling, safety boundaries, evaluation cases, and handoff contracts around the reclamation workflow.

The handoff status is `candidate` with analytical evidence. The current equilibrium record is [`equilibrium-review-record.json`](../review/equilibrium-v0.1.0-post-refinement/equilibrium-review-record.json), which records a provider-neutral dry run with `defer-for-evidence`. Before publication or a live claim, run independent reviewer execution, a protected or external holdout, and human/domain review for the relevant transaction semantics.

The machine-readable package inventory, hashes, authorization boundary, unresolved evidence, and recovery guidance are in [`family-promotion-manifest.json`](family-promotion-manifest.json).
