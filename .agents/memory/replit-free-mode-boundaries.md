---
name: Replit Free Mode boundaries
description: Host-controlled limits and approval rules that affect reusable Free Mode autonomy guidance
---

Free Mode autonomy can reduce waste, checkpoint blocked work, and schedule a
bounded retry opportunity when the host supports routines. It cannot force a
quota reset, create a global cross-project timer, hide platform notices, or
accept sensitive approvals on the user's behalf.

**Why:** Replit documents that routine failures are not automatically retried
and that sensitive actions require human-in-the-loop approval. Treating a timer
or local instruction as authority would create false completion or bypass a
safety boundary.

**How to apply:** When creating or reviewing Replit workflow guidance, state the
conversation scope, use at most one safe retry per scheduled run, verify actual
success, and stop for approval-sensitive actions.
