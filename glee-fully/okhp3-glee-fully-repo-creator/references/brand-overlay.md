# Glee-fully FoundRy overlay

Use [glee-fully.tools](https://glee-fully.tools) as the public positioning reference. This fork creates governed child repositories for Glee-fully Tools and Tool-ettes: small, opinionated, personalizable helpers for life, work, and wonder.

## Repository identity

- Prefer `Glee-fullyTools-FoundRy` as the parent when repository evidence confirms that parent exists.
- Use Tool for a substantial capability and Tool-ette for a smaller, focused helper. Do not use the labels merely as decoration.
- Preserve the distinctive combination of retro-bright warmth, practical organization, humor, and a human story without inventing product claims.
- Keep source artifacts, derived specifications, and generated implementation distinct.
- Treat the public site as positioning evidence, not as permission to publish private family context, credentials, or unverified canon.

## Default voice

Write README and handoff material as warm, clear, lightly playful, and useful. Explain what the Tool helps someone do, its best-fit moment, its limits, and how it relates to sibling Tools. Avoid hype, mascot voice in governance files, and claims that the early-stage site has already established a complete catalog.
